# CyberSentry: Terminal Defense

A high-fidelity, cyberpunk-themed tower defense game built with Vanilla JavaScript and HTML5 Canvas. Secure the system against incoming data threats across multiple sectors.

![CyberSentry Mockup](cybersentry_mockup_1777824304276.png)

## 🚀 Features

-   **High-Fidelity Neon Visuals**: Real-time glow effects, dynamic geometries, and particle-based explosions.
-   **Advanced Tower Arsenal**:
    -   **Pulse Turret**: Rapid-fire energy discharge.
    -   **Railgun**: High-power kinetic penetrator for heavy targets.
    -   **Nova Mortar**: Seismic area-of-effect blasts.
    -   **Stasis Field**: Advanced crowd control that slows incoming threats.
-   **Dynamic Enemy Threats**: Scouts, Tanks, Glitchers (with jitter-movement), and multi-layered Bosses.
-   **Multi-Sector Campaign**: Secure Alpha, Beta, and the Core Terminal across 18 challenging waves.
-   **Polymorphic Architecture**: Robust, extensible Object-Oriented design for easy expansion of game entities.
-   **Full Test Suite**: 31 unit tests covering engine logic, entity behavior, and progression.

## 🛠️ Technology Stack

-   **Frontend**: HTML5 Canvas, Vanilla JavaScript (ES6+).
-   **Styling**: Vanilla CSS with Grid/Flexbox and Orbitron typography.
-   **Build Tool**: Vite.
-   **Testing**: Vitest.

## 🎮 How to Play

1.  **Select a Tower**: Click a tower in the Arsenal (bottom bar).
2.  **Place Tower**: Move your mouse to the grid and click to deploy (ensure you have enough Gold).
3.  **Start Wave**: Click the "Start Wave" button at the top to begin the hack attempt.
4.  **Upgrade/Sell**: Click on a placed tower to see its stats. Upgrade to increase range and damage, or sell to recoup full value.
5.  **Victory**: Prevent enemies from reaching the end of the path. If lives reach 0, the system is compromised!
